# ODYSSEOS

Premium sports nutrition experience with dual-layer mask-reveal hero, glass UI, categories, and GSAP product showcase.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

Then visit the URL shown (typically `http://localhost:3000`).

## Assets

Images load from DigitalOcean CDN URLs defined in `index.html`.
